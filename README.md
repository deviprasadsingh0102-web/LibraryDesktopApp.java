# Library Management System (Desktop Application)

## Description
This project is a Library Management System developed in Java.
It allows users to manage books including adding, viewing, searching, and deleting records.

## Features
- Add books
- View books
- Search books
- Delete books

## Technologies Used
- Java
- ArrayList
- Scanner
- Control Flow

## How to Run
1. Open in VS Code / NetBeans
2. Compile program
3. Run LibraryDesktopApp.java
